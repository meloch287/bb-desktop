# bb для Windows

Установщик приложения bb — рабочей зоны GPT и Claude.

**Скачать:** [bb-setup.exe](https://github.com/meloch287/bb-desktop/releases/latest/download/bb-setup.exe)

После установки отправь боту команду /desktop и вставь ссылку подключения в приложение.

Windows может предупредить, что установщик без подписи: «Подробнее» → «Выполнить в любом случае».
