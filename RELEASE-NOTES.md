# bb 1.5.0

- Новый VPS стал основным маршрутом для интерфейса, служебных настроек и метаданных обновлений. Прежнее зеркало и другие резервные маршруты сохранены.
- Добавлено ограниченное восстановление после сетевого сбоя загрузки модуля интерфейса: один повтор текущего адреса, затем одна попытка другого адреса. Наблюдение за каждой стартовой загрузкой ограничено 90 секундами.
- Поддержана необязательная локальная настройка `network.json` с HTTP-прокси `mirrorProxy`. При недоступности прокси используются обычные маршруты; идентичность устройства сохраняется.
- Сохранена поддержка `edge-override.json` из Windows 1.4.2, включая приоритет явного локального профиля прокси.
- Подготовлены установщик Windows x64 и архивы macOS для Apple Silicon и Intel.

Windows-установщик не подписан. Mac-архивы имеют ad-hoc-подпись и не нотариализованы Apple. Инструкции первого запуска и обновления приведены в README.
